## اصلاحیه

در گزارش‌های قبلی نوشته بودم CI سبز است. منظورم تست‌های داخل محیط خودم بود. CI در GitHub از #66 به بعد قرمز بود و همه برطرف شد:
- ۸ تست آپلود فایل روی سیستم‌های غیر root خطا می‌دادند. حالا تست‌ها پوشه‌ی موقت می‌گیرند.
- GitHub سیستم تست را به Ubuntu 26.04 برده بود و Playwright روی آن نصب نمی‌شد. نسخه روی 24.04 ثابت شد.
- تست‌های e2e در GitHub به‌خاطر کامپایل اول صفحه‌ها ناپایدار بودند. حالا با یک worker، زمان بیشتر و یک بار تکرار اجرا می‌شوند، و تست استرداد اول صفحه‌هایش را کامپایل می‌کند.
- ساخت image داکر backend پوشه‌ی `catalog_data` را نمی‌یافت، چون فقط روی سرور است. در CI یک پوشه‌ی خالی ساخته می‌شود.

# ورود کارکنان با رمز ثابت — راهنمای تنظیم رمز روی سرور

درخواست مالک ۱۴۰۵/۰۹/۰۸ (ثبت در `docs/product/approvals.md`): تا وقتی پیامک کاوه‌نگار کار نمی‌کند، کارکنان و مدیر
می‌توانند در صفحهٔ `/login` با «ورود کارکنان با رمز» وارد شوند.

## قواعد
- فقط حساب‌های کارکنان/مدیر رمز می‌گیرند: `backoffice_expert`، `finance_operator`، `tenant_admin`، `platform_admin`. حساب مشتری رمز نمی‌گیرد.
- رمز **فقط از کنسول سرور** تنظیم می‌شود؛ هیچ صفحه یا API وب برای تنظیم رمز وجود ندارد.
- رمز حداقل ۱۰ کاراکتر است، دو بار به‌صورت مخفی پرسیده می‌شود و هیچ‌جا چاپ یا ذخیرهٔ خوانا نمی‌شود (فقط hash).
- ۵ تلاش اشتباه = حساب ۱۵ دقیقه قفل (همان قفل ورود پیامکی). اگر ورود دومرحله‌ای (Authenticator) فعال باشد، بعد از رمز کد برنامه هم لازم است.
- هر تنظیم رمز و هر ورود در جدول audit ثبت می‌شود. چیزی پاک نمی‌شود.

## مراحل (کنسول ابرآروان یا ssh روی سرور)

۱. فهرست حساب‌های کارکنان را ببینید (فقط خواندنی؛ شماره و ایمیل نیمه‌پنهان نمایش داده می‌شود):

```
cd /opt/karenseir && docker compose exec api python -m scripts.set_staff_password --list
```

از خروجی، `tenant=...` حساب خودتان را بردارید.

۲. رمز را تنظیم کنید (شمارهٔ همراه خودتان را به‌جای `09...` بنویسید):

```
cd /opt/karenseir && docker compose exec api python -m scripts.set_staff_password --tenant <tenant> --mobile 09...
```

اگر حساب شماره ندارد، به‌جای `--mobile` از `--email <ایمیل حساب>` استفاده کنید.
دستور دو بار رمز را می‌پرسد؛ هنگام تایپ چیزی دیده نمی‌شود. پیام «انجام شد» یعنی رمز ثبت شد.
برای عوض کردن رمز، همین دستور را دوباره اجرا کنید.

۳. ورود: در `https://karentravel.ir/login` روی «ورود کارکنان با رمز» بزنید؛ در «سازمان» همان `tenant`، بعد شماره همراه
(یا ایمیل) و رمز را وارد کنید.

## پیام‌های خطای دستور
- «نقش این حساب ... کارکنان/مدیر نیست»: این حساب مشتری یا نقش سازمانی است و رمز نمی‌گیرد؛ حساب کارکنان لازم است.
- «حسابی ... پیدا نشد» یا «tenant پیدا نشد»: با `--list` شماره/tenant را دوباره بررسی کنید.
- «باید در کنسول تعاملی اجرا شود»: دستور را با `-T` یا از داخل اسکریپت اجرا نکنید؛ مستقیم در کنسول تایپ کنید.

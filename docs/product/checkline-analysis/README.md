# تحلیل چک‌لاین و نقشه‌ی فرایندهای کارن‌سیر

این پوشه مرجع مشترک تحلیل ساختار چک‌لاین (پیشخوان وردپرس، پنل سیتی‌نت، هاب سیتی‌نت و تعرفه‌ی خدمات سیتی‌نت ۱۴۰۴) و فرایندها و مدل داده‌ی پیشنهادی کارن‌سیر است. فقط مستندات است و هیچ کد، دیتابیس یا Production را تغییر نمی‌دهد.

## فایل‌ها

| فایل | محتوا |

| `DESIGN_SCREENS.md` | فهرست ۱۸ صفحه‌ی طراحی‌شده در فیگما و ایده‌های سایت‌های مرجع |

## طراحی در فیگما

فایل فیگمای KarenSeir، صفحه‌ی «KarenSeir — فرایندها و مدل داده (از تحلیل چک‌لاین)»:
https://www.figma.com/design/Ei8MUR9VN2yCX6BLOpvTXm/KarenSeir?node-id=167-2

بخش‌ها: معماری فعلی ← طرح کارن‌سیر، مدل داده (۱۶ موجودیت)، ده فرایند (فروش، قیمت‌گذاری و درآمد، پرداخت و صندوق، کنسلی و استرداد، تأمین، چارتر، حسابداری، سازمانی و اقساط، حلقه‌ی همسفران، سفرساز و انتشار)، نقش‌ها و دسترسی‌ها، مشکل ← تصمیم طراحی، کاتالوگ اتصال‌ها، و سایت وایت‌لیبل checkline.ir.

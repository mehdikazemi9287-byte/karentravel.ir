## Coverage vs. request
- Agency today (AG-01) · profile + licences with per-registry verification (AG-02) · sub-agencies list + create (AG-19) · wallet/credit, top-up request, statement (AG-15) · markup & commission rules with CAO-cap preview (AG-07) · tours list (AG-08) + editor with departures, capacity, ADT/CHD/INF prices, tax, refund policy (AG-08a) · charter flights list with domestic flag (CH-01) · seat block form with fare classes, name-change deadline, refund rule, release, PRICE_CAP_EXCEEDED error (CH-02) · CSV import validation preview + provider/API status (Parto etc. «پس از قرارداد») (AG-11/12) · received bookings + manifest with masked IDs (AG-13/14) · settlement cycle/statement/dispute form (AG-17) + dispute thread (AG-18) · white-label settings with themed preview using the WL token mode (AG-WL) · staff: OPS-09 onboarding/verification queue (desktop + mobile), FIN-05 settlement run with maker-checker (desktop).

## Known limitations
- Sidebar has no `Area=agency` variant in the library; agency frames use the `finance` variant with overridden labels (10 items, 3 groups). Profile / white label share one menu item. Recommend adding an agency variant to the library.
- MoneyBreakdown has no `agency_seller` view; AG-17 overrides the `customer` view text.
- Loading/empty/error/no-access variants per frame (spec §5) are not drawn for P2.
- Gregorian helper dates in JalaliDateField can render reversed by bidi (e.g. "16 Nov 2026"), same as the library default.

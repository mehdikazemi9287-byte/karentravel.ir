## پیشنهاد: هم‌سان‌کردن `main` با `production` (اجرا نشده)

`main` شاخه‌ی پیش‌فرض است ولی ۲۵۳ commit عقب‌تر و هیچ commit جلوتری ندارد؛ پس هم‌سان‌کردن آن بدون conflict است. یکی از دو راه:

۱. **تغییر شاخه‌ی پیش‌فرض به `production`** (پیشنهاد اصلی): در Settings ← Branches ← Default branch. با این کار PRهای تازه و clone تازه از شاخه‌ی زنده شروع می‌شوند. بعد `main` یا حذف شود یا فقط از `production` به‌روز شود.
۲. **نگه‌داشتن `main` و به‌روزکردن fast-forward:** یک PR از `production` به `main` (fast-forward، بدون commit ادغام)، یا با دسترسی مدیر: `git push origin production:main`. از آن به بعد پس از هر انتشار تکرار شود، یا قانون محافظت شاخه آن را خودکار کند.

ترتیب پیشنهادی: (۱) بستن PRهای #1، #2، #4؛ (۲) تغییر شاخه‌ی پیش‌فرض یا هم‌سان‌کردن `main`؛ (۳) ساخت tag برای دو شاخه‌ی دسته‌ی ج؛ (۴) حذف شاخه‌های دسته‌ی الف و ب.

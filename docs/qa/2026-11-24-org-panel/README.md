## e2e دو-زمینه‌ای (مورد ۸.۴) — `e2e/panels/dual-context.spec.ts`
یک حساب `customer` که عضو سازمان الف (بدون مجوز) و مدیر سازمان ب است (عضویت‌ها و مجوزها با API واقعی: tenant-admin سازمان می‌سازد و عضو اضافه می‌کند؛ org-admin مجوز می‌دهد):
1. `/account`: جابه‌جاکننده هست و «حساب شخصی» فعال است؛ نام هیچ‌کدام از دو سازمان، «اعتبار سازمانی» و منوی «مزایای سازمانی» نیست.
2. جابه‌جاکننده ← `/organization` («نمای کلی») و داشبورد سازمان ب (محل مدیریت) را باز می‌کند، نه اولین عضویت. ۹ صفحهٔ مجاز بدون «دسترسی ندارید» و **بدون هیچ پاسخ 403 از API** باز می‌شوند. `structure`، `passengers`، `financial-context` (فقط با نقش) «دسترسی ندارید» نشان می‌دهند.
3. برگشت به «حساب شخصی»: همان توکن در sessionStorage و همان localStorage (نشانگر آزمون)؛ دوباره رفتن به پنل سازمان هم کار می‌کند.
4. مشتری ساده (۱۴۴۰ و ۳۹۰): جابه‌جاکننده ندارد و `/organization` «دسترسی ندارید» است.

**یافته و رفع:** در اجرای اول، صفحهٔ «سوابق و گردش تأیید» برای مدیرِ با عضویت `GET /organization/overview` را صدا می‌زد که با نقش سراسری محافظت می‌شود و 403 برمی‌گرداند. حالا این فراخوانی و کارت «گردش‌های تأیید رزرو» فقط برای نقش‌های مجاز همان endpoint است.
